# Hi there 👋

**Road from Vibe Code to Full Stack.**

I'm a developer with a background in software development training, currently working towards my first full time role in IT. I like building practical tools for my own home lab, learning by shipping small projects, and running AI models locally on my own hardware.

## Projects

### Java
- [java-lern-app](https://github.com/ththema-bit/java-lern-app): Swing desktop app for learning Java and preparing for junior developer interviews, with lessons, quizzes and a built in code runner.
- [banking-sim](https://github.com/ththema-bit/banking-sim): console banking simulation in plain Java with a detailed code walkthrough.

### Local AI and tooling
- [vllm-rtx3090-tuning](https://github.com/ththema-bit/vllm-rtx3090-tuning): scripts for running and tuning vLLM on multi RTX 3090 machines (power limits, fan control, benchmarks, tool call tests).
- [openclaw-claude-code](https://github.com/ththema-bit/openclaw-claude-code): TypeScript plugin that lets an OpenClaw agent hand coding jobs to the Claude Code CLI.
- [browser-copilot](https://github.com/ththema-bit/browser-copilot): Chrome extension plus Node.js bridge that lets a local agent see, highlight and click in the browser.

### Web tools
- [lol-runes](https://github.com/ththema-bit/lol-runes): League of Legends rune page simulator built on Data Dragon data.
- [home-lab-dashboard](https://github.com/ththema-bit/home-lab-dashboard): static landing page for home lab services with status checks.
- [gifmaker](https://github.com/ththema-bit/gifmaker): browser based GIF, MP4 and WebM mixer with a small ffmpeg backend.
- [frame-mixer](https://github.com/ththema-bit/frame-mixer): alternate the frames of two videos and export WebM, fully client side.
- [ui-kit](https://github.com/ththema-bit/ui-kit): tiny dark CSS kit used across these tools.

### Python
- [filmdev](https://github.com/ththema-bit/filmdev): desktop tool that turns RAW analog film scans into inverted 16 bit TIFFs.
- [print-generators](https://github.com/ththema-bit/print-generators): generators for print ready art and templates (star maps, city maps, mandalas, TTRPG sheets).
- [aion2-market-monitor](https://github.com/ththema-bit/aion2-market-monitor): daemon that tracks Aion 2 market prices in SQLite and derives price signals.
